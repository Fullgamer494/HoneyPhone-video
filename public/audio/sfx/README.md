# Efectos de sonido locales

Estos efectos se prepararon para incorporarse al montaje HoneyPhone. Se conservan sus fuentes y licencias:

| Archivo | Origen | Licencia / atribución |
|---|---|---|
| `mouse-click.wav` | [Remotion SFX: Mouse Click Sound](https://www.remotion.dev/docs/sfx/mouse-click), Pixeliota | CC0 |
| `switch.wav` | [Remotion SFX: UI Switch](https://www.remotion.dev/docs/sfx/ui-switch), Kenney | CC0 |
| `page-turn.wav` | [Remotion SFX: Page Turn](https://www.remotion.dev/docs/sfx/page-turn), Kenney | CC0 |
| `whoosh.wav` | [Remotion SFX: Whoosh](https://www.remotion.dev/docs/sfx/whoosh), 1bob | CC0 |
| `whip.wav` | [Remotion SFX: Whip](https://www.remotion.dev/docs/sfx/whip), JW_Audio | CC0 |
| `glass-slide.mp3` | [Glass plate slide, Mixkit](https://mixkit.co/free-sound-effects/slide/) | Mixkit License; incorporarlo al video final, no redistribuir el MP3 aislado |

Usa los efectos solo cuando coincidan con una acción visible. Mantén taps, barridos y foley por debajo de la voz.
