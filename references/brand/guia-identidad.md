# Guía visual — HoneyPhone

La edición toma como referencia los recursos reales y la interfaz Android del proyecto.

## Paleta

| Uso | Color |
|---|---|
| Fondo | `#000000` |
| Superficie elevada | `#0B0B0B` |
| Texto principal | `#F4F4F4` |
| Texto secundario | `#B8B8B8` |
| Acento HoneyPhone | `#F5B700` |
| Alerta | `#FFD166` |
| Bordes y divisores | `#292929` |

## Tipografía y marca

- **Unbounded:** titulares y rótulos cortos.
- **Plus Jakarta Sans:** narración en pantalla, descripciones y créditos.
- **JetBrains Mono:** datos, métodos HTTP y lecturas técnicas.
- **Doto:** acentos puntuales de estilo digital.
- Usar `logo_sin_fondo.png` como marca principal para evitar el bloque negro del logo rasterizado.

## Criterios de composición

- Contraste alto y espacios amplios; las tarjetas tienen bordes finos y esquinas suaves, no una estética de cajas rígidas.
- El ámbar identifica acciones y datos destacados; reservarlo para llamadas visuales, sin convertirlo en fondo dominante.
- Mantener la captura completa del teléfono dentro del marco; evitar acercamientos que corten etiquetas o contenido.
- Las referencias de marca y fotogramas de la app se incluyen en `references/brand/` y `references/screens/`.
