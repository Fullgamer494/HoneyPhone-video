# Voces del proyecto

La voz activa del video es ElevenLabs. Los diez MP3 finales y la música están en `../voice/eleven-labs/`; también hay una copia pública lista para Remotion en `../public/audio/voice/eleven-labs/`. Consulta `../docs/voz-eleven-labs.md` para duraciones, mezcla y subtítulos.

`voice/audio/` y los scripts `generate-voice.sh` / `join-voice.sh` corresponden a una versión anterior con Kokoro. No los uses para reemplazar la voz ElevenLabs.
